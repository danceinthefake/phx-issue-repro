# Evidence for `repro/live_vue_mounted_race`

Static artefacts captured against this branch with the upstream
`live_vue` 1.2.1 dep (broken) vs the same code with a path-linked
fork (fixed). Generated by the headless Playwright capture
described in `REPRO.md` — the video has a deliberate 200 ms
`slow()` wrapper on the lazy glob so the race fires every load
instead of intermittently.

|---|---|---|

## Redactions

The captured stack traces originally contained Linux filesystem
paths (`/home/<username>/...`) and the GitHub org name
(`danceinthefake/...`). The capture script regex-replaces these
to `/home/user/<user>/...` before any pixel is written to video
or text to disk. No personal identifiers leak through these
files.

## Reproducing the capture

If you want to regenerate these artefacts from scratch:

```sh
# 1. broken-state capture (uses the upstream live_vue from hex)
mix setup
mix phx.server &
# in another shell:
URL=http://localhost:4000/race LABEL=phx-repro \
  node /tmp/live_vue_demo/capture.mjs

# 2. flip to the fork
sed -i 's|"live_vue": "file:./deps/live_vue"|"live_vue": "file:../live_vue"|' package.json
rm -rf node_modules/live_vue node_modules/.vite
npm install
mix phx.server &
URL=http://localhost:4000/race LABEL=phx-fixed \
  node /tmp/live_vue_demo/capture.mjs

# 3. compose
ffmpeg ... # see capture.mjs comment block
```

`capture.mjs` lives at `/tmp/live_vue_demo/capture.mjs` in the
working directory it was authored in; if you don't have it, the
Playwright script is small enough to rewrite from the
description above (launches chromium headless, opens the URL,
listens for `pageerror`, dumps to console.txt + a Playwright
video). The `slow()` wrapper that makes the race deterministic
already lives in this branch's `assets/vue/index.ts` — no
capture-side tricks needed beyond the redaction.
